## 2026-04-08 — mje0002: Context Graph Linker Refactor

### What Went Well

- Script-first architecture decision proved correct — moving deterministic file mutations from a 260-line skill to `scripts/graph-link.sh` made the logic auditable, testable, and version-controlled
- Two-layer sync strategy (manual step in context-maintenance skill + automatic pre-commit hook) provides good coverage without being intrusive
- Thin skill stub pattern maintained discoverability while avoiding duplication of procedural logic
- Bash 3 compatibility ensured the script works on stock macOS without Homebrew dependencies
- Coder agent completed all remaining work autonomously with clear delegation context

### What Could Be Improved

- Task was started before global task tracking (mje0006) was implemented, so it wasn't registered in active-tasks.json → Made task resumption less automatic
- Initial script implementation missed `--help` flag: Users got "Unknown flag" instead of usage info → Add help handlers to all new scripts during implementation, not as afterthought
- Several context files lack proper frontmatter descriptions, causing TODO placeholders in generated INDEX.md → Need to audit existing .context/ files and add descriptions

### Lessons Learned

- **Script-first for file mutations**: Skills that create directories and rewrite files belong in scripts, not agent instructions. Scripts are composable, testable, and can be called by both agents and humans.
- **Hook safety patterns**: Pre-commit hooks should (a) check for initialization state, (b) be no-op if not applicable, (c) auto-stage generated files, (d) provide clear output on what changed
- **Thin skill stub pattern**: Keep ~100-line stub explaining *when* to invoke a script, while procedural *how* lives in the script itself. Maintains discoverability without duplication.
- **Type taxonomy alignment**: Always validate categorization schemes against actual directory structure — the original skill's types didn't match context_template and would have caused misclassification
