## Task ID Convention

All tasks in this repository use the following ID pattern:

**Format:** `MKT-####`
- Prefix: `MKT-` (uppercase)
- Number: 4-digit zero-padded (0001, 0002, etc.)
- Separator: hyphen

**Examples:**
- MKT-0001
- MKT-0002
- MKT-0042
- MKT-0150

**Next available ID:** Check `.context/tasks/` and use the next sequential number.

**Folder structure:**
- `.context/tasks/MKT-####/plan.md`
- Branch naming: `feature/MKT-####-description` or `bugfix/MKT-####-description`
